# Arsip Sesi Analisis — 28 September 2026

Folder ini adalah catatan penutup sesi agar pekerjaan dapat dilanjutkan tanpa menebak state sebelumnya.

## Tujuan sesi

Menyiapkan pipeline pengenalan urutan huruf Hijaiyah sambung berbasis CNN-LSTM, dengan entrypoint Google Colab `.ipynb`, transfer learning MobileNetV4, dan output yang hanya berisi 28 huruf Hijaiyah tanpa harakat.

## Isi arsip

- `STATUS_SESI.md` — kondisi aktual dan riwayat pekerjaan.
- `CATATAN_TEKNIK.md` — keputusan arsitektur, data, dan batasan.
- `LANGKAH_LANJUT.md` — urutan pekerjaan berikutnya.
- `RENCANA_NOTEBOOK_COLAB.md` — rancangan sel notebook utama.
- `CHECKLIST_RESUME.md` — checklist aman saat melanjutkan.
- `MANIFEST_SESI.json` — metadata arsip.

## Aturan melanjutkan

1. Baca `STATUS_SESI.md` sebelum membuat atau mengubah file.
2. Jangan menjalankan `git clean`, `git reset --hard`, `Remove-Item`, atau operasi penghapusan massal.
3. Jangan menganggap metrik data demo sebagai hasil skripsi.
4. Jangan mengubah output menjadi harakat, huruf Latin, atau hamza terpisah.
5. Jika folder project kembali kosong, gunakan langkah rekonstruksi pada `LANGKAH_LANJUT.md`.
